## 1. Git标签

1. 打标签

```sh
git tag 标签名

# 如果需要给标签添加注释信息，可以使用以下命令：
git tag -a 标签名 -m “注释信息”
```


2. 验证标签是否创建成功

```sh
# 列出所有已创建的标签
git tag
```

3. 将本地标签推送到远程

```sh
git push origin 标签名

# 如果需要将多个标签一次性推送到远程仓库，可以使用以下命令：
git push origin –tags
```

4. 验证标签是否成功推送到远程仓库

```sh
# 列出远程仓库上的所有标签
git ls-remote –tags origin
```
